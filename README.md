# Marco Beenen - Windows Tools

Windows diagnose-, onderhouds- en hulppakket voor Windows, gemaakt door Marco Beenen.

## Nieuwste versie

De huidige pakketversie is **v4.3**.

- Download het ZIP-bestand uit de hoofdmap.
- Pak de ZIP volledig uit voordat u de tools gebruikt.
- Start het pakket via `START - Windows Tools.bat`.
- Lees vooraf de meegeleverde TXT- of PDF-handleiding.

## Inhoud

Het pakket bevat diagnose- en rapportagetools, Windows-hulpmiddelen, onderhoudsopties, energieopties en een alleen-lezen RDP Wrapper-diagnose.

## Belangrijke waarschuwing

Gebruik `format-disk-2.bat` **niet zomaar**. Gebruik dit bestand alleen als u DiskPart en de risico's begrijpt en precies weet welke fysieke schijf Windows als Disk 2 aanduidt. Alle partities en bestanden op Disk 2 kunnen worden verwijderd. Disk 2 is niet hetzelfde als stationsletter D:.

## Veilig gebruik

Maak eerst een back-up van belangrijke bestanden. Voer reparaties, scans, updates, herstelacties, uitschakelingen en formatteringen alleen bewust uit. De meeste diagnose- en rapportagefuncties zijn alleen-lezen, maar niet ieder onderdeel is zonder gevolgen.
